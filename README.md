# Credium — Team Obsidian · CASCADE '26

PS 4.2 *The Black Hole Ledger* · Theme 4 *Information Asymmetry*

Purpose-bound NGO escrow where vendors sign their bills. If an NGO claims one bill twice, across donors or chains, its own two signatures prove it, and anyone can freeze the vault. No auditor and no admin key are needed. Mechanism: **two-signature equivocation freeze**.

All bills, vendors, keys and pledges are **SYNTHETIC / SIMULATED** and labelled as such.
